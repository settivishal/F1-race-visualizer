Team marks go here, as `<team>.svg`, and each one is listed in
`src/lib/team-marks.ts` with its source and licence.

Nothing is shown for a team that has no entry there, and the credit on /about is
written from that same list — so a file dropped in here alone changes nothing,
which is deliberate: the site does not republish an image whose licence is not
written down. See docs/decisions.md, "Reversal: images are not mirrored into
Vercel Blob".
